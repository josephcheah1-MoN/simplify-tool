# 表达式简化工具

粘贴原始短信文本，自动整理成标准格式。单文件网页，手机（iOS/安卓）和电脑都能用。

## 使用

直接打开 `index.html`，或部署到 GitHub Pages 后访问网址。

- 粘贴文本后自动出结果，也可点「简化」
- 「复制结果」一键复制；或轻点结果区全选后长按复制
- iPhone：Safari 打开后「分享 → 添加到主屏幕」可当 App 使用

## 支持的写法

时间戳/前缀去除、`=`/`/`/`～`/`—`/`_` 各种比例写法、`大`/`小`/`b`/`s`、`打`/`全打`/`box`/`R` 前缀加 r 标记、`all` 标记词、括号号码加 r、四位数串联拆分等。
